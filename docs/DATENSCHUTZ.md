# Datenschutz · Kunterbunt City

## Für Kinder
**Dieses Spiel sammelt keine Daten.** Es weiß nicht, wer du bist, und erzählt niemandem etwas.
Alles, was du baust, bleibt nur auf deinem Gerät.

## Für Eltern
- **Keine Datensammlung:** keine Konten, keine Analyse, keine Werbung, keine Tracker, keine Absturzberichte.
- **Kein Internet:** Das Spiel enthält keinen Netzwerk-Code (automatisch geprüft bei jedem Bau, Test `test_no_network`).
  Es funktioniert komplett offline.
- **Was lokal gespeichert wird:** Figuren, Haustiere, eingerichtete Räume, Album-Fotos und Einstellungen – nur auf diesem
  Gerät, im Benutzerordner des Spiels (Windows: `%APPDATA%\Godot\app_userdata\Kunterbunt City`).
  Es werden automatisch zwei Sicherungen des Spielstands angelegt.
- **Löschen:** Eltern-Bereich (Eltern-Tor) → Einstellungen → „Alles löschen“. Beim Deinstallieren bleiben Spielstände
  absichtlich erhalten; zum vollständigen Entfernen den oben genannten Ordner löschen.
- **Namen:** Kinder wählen Namen aus einer Liste. Freie Eingabe gibt es nur hinter dem Eltern-Tor; der Name bleibt auf dem Gerät.
- **Kosten:** 0 €. Keine In-App-Käufe, keine Lootboxen, keine Warte-Mechaniken.

Stand: Version 1.0.0
