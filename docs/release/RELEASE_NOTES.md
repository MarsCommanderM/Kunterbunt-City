## Kunterbunt City – Download

**Windows (empfohlen):** `KunterbuntCity-Setup-….exe` herunterladen und doppelklicken → „Installieren“.
Danach liegt **Kunterbunt City auf dem Desktop** – ein Klick genügt. Keine Admin-Rechte nötig.
Falls Windows „Der Computer wurde durch Windows geschützt“ meldet: **Weitere Informationen → Trotzdem ausführen**
(das Spiel ist nicht kostenpflichtig signiert).

**Windows ohne Installation:** `KunterbuntCity-Windows-….zip` entpacken, `KunterbuntCity.exe` doppelklicken.

**Linux:** `KunterbuntCity-Linux-….tar.gz` entpacken, im Ordner `./installieren.sh` ausführen → Symbol auf dem Desktop.

**macOS:** `KunterbuntCity-macOS-….zip` entpacken, App mit **Rechtsklick → Öffnen** starten (nicht signiert).

**Im Browser:** `KunterbuntCity-Web-….zip` (für itch.io / eigene Webseite).

100 % kostenlos · keine Werbung · keine In-App-Käufe · keine Datensammlung · kein Internet nötig.
