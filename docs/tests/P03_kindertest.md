# Kindertest Phase 03 · Figuren & Tiere 👤

**Ziel:** Verstehen Kinder ohne Erklärung, wie man Figuren anfasst, hinsetzt und Dinge in die Hand gibt?
**Dauer:** 10 Minuten · **Wer:** 1–2 Kinder (4–8 Jahre) · **Wann:** nach Phase 03, vor Phase 04.

## Vorbereitung
1. Spiel starten → „Figuren-Sandbox“ (Test-Küche mit Figuren).
2. Tablet oder PC mit Touch/Maus, Ton an.
3. **Nichts erklären.** Nur sagen: „Du kannst alles anfassen.“

## Aufgaben (beobachten, nicht helfen)
| # | Aufgabe | Ohne Hilfe geschafft? | Wie lange? | Was hat verwirrt? |
|---|---|---|---|---|
| 1 | Figur am Körper ziehen und woanders hinstellen | ☐ ja ☐ nein | ☐ < 5 s ☐ 5–20 s ☐ > 20 s | |
| 2 | Karotte vom Tisch in die Hand der Figur geben | ☐ ja ☐ nein | | |
| 3 | Figur auf den Stuhl setzen | ☐ ja ☐ nein | | |
| 4 | Kleinkind ins Bett legen | ☐ ja ☐ nein | | |
| 5 | Eis an den Mund halten (essen) | ☐ ja ☐ nein | | |
| 6 | Kopf antippen (Gesicht wechselt) | ☐ ja ☐ nein | | |
| 7 | Hund antippen (bellt) | ☐ ja ☐ nein | | |

## Beobachtungen
- Was haben sie als Erstes probiert?
- Haben sie erwartet, dass die Figur sitzt, wenn man sie auf den Stuhl zieht? ☐ ja ☐ nein
- Haben sie das Item in der Hand wieder herausbekommen? ☐ ja ☐ nein · Wie?
- Haben sie gelacht/gekichert, als die Figur beim Tragen gependelt ist? ☐ ja ☐ nein
- Wo haben sie etwas anderes erwartet als passiert ist?
